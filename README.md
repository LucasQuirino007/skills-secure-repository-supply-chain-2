# Proteja a cadeia de suprimentos do seu repositório

_Proteja sua cadeia de suprimentos, entenda as dependências do seu ambiente, saiba quais vulnerabilidades existem nelas e corrija-as._

## Boas-vindas

O GitHub ajuda você a proteger sua cadeia de suprimentos: desde entender as dependências do seu ambiente até conhecer as vulnerabilidades dessas dependências e corrigi-las.

- **Para quem é este exercício**: Pessoas desenvolvedoras, engenheiras de DevOps, Site Reliability Engineers e especialistas em segurança
- **O que você vai aprender**: Como visualizar as dependências de um repositório, ver alertas do Dependabot e habilitar security updates e version updates do Dependabot
- **O que você vai construir**: Dependências do repositório, alertas do Dependabot e pull requests para corrigir dependências e atualizar versões
- **Pré-requisitos**: Nenhum
- **Duração**: Este exercício pode ser concluído em menos de uma hora

Neste exercício, você vai explorar:

1. Dependency graph
2. Alertas de dependências
3. Security updates de dependências
4. Version updates de dependências

### Como iniciar este exercício

Basta copiar o exercício para a sua conta, dar à sua Octocat favorita (Mona) **cerca de 20 segundos** para preparar a primeira lição e depois **atualizar a página**.
